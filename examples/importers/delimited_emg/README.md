# Example Delimited EMG Importer

This working reference pack accepts a synthetic CSV with `time_ms`, `emg_1`, and `stimulus_v` columns. It demonstrates validation, canonical metadata, managed-store output, cancellation, and provenance of the importer identity.

Package this folder so that `manifest.json` is at the root of the ZIP. It is intentionally not distributed as a supported importer for any commercial acquisition system.
