### Settings and Defaults Note:

MonStim default settings are not universally valid constants. Validate cutoff frequencies, latency windows, stimulus spacing, and M-max settings against your own acquisition protocol, muscle(s), species, and analysis plan before treating an output as a scientific conclusion.
