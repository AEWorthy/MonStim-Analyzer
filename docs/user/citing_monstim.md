# How to cite MonStim

If MonStim Analyzer contributes to an academic publication, presentation, thesis, dataset, or derived analysis, please cite the version used.

## Preferred citation

Use the repository’s `CITATION.cff` entry, GitHub’s **Cite this repository** control, or **Help > Copy Citation** in MonStim. The current software citation identifies the application, version, author, and repository URL.

## Preserve provenance

When exporting a CSV preview from MonStim, retain its adjacent `.provenance.json` file. It records the MonStim version, recommended citation, installed importer identities, and available analysis context without altering the CSV table.

For a report or manuscript, record the MonStim version, analysis profile, amplitude method, latency windows, exclusions, and any importer add-on version. These details help readers reproduce the analysis and allow future users to identify the appropriate citation.
